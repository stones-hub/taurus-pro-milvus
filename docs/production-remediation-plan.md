## 范围

1. Search 正确向 SDK 传递 vectorField、metricType、params，使用 SDK 正式选项，保留现有公开方法签名。
2. MustGet 同名并发请求复用同一创建结果，Add 重名仍报错。
3. 网络建连不持有池全局锁；提供有界默认建连超时及可由调用方 context 控制的入口，原接口保持兼容。Close/Remove/并发创建的生命周期必须明确且不泄漏新连接。Close 为终态，关闭后拒绝新 Add/MustGet；该语义需文档说明。
4. 测试地址、账号、密码从环境读取；未启用集成测试时不访问外部服务器，显式启用后配置不足/连接失败必须失败而非跳过。测试自己准备所需数据库、别名和集合并清理，不以业务错误作为跳过理由。
5. 增加独立于服务器的并发/失败路径回归，保留真实集成测试；纠正 README 自动负载均衡等与实际实现不符描述。

## 边界

不升级依赖、不重构无关 API、不提交/推送/部署、不访问 113。客户端写锁跨 RPC 的整体重构、TLS 全功能扩展、限流重试 SDK 契约的进一步整改不在本次最小修复范围；如发现必要阻断先报告。
